# Example project / Projeto de exemplo

`dominus-dixit.mocquereau` is the example project bundled with Mocquereau (Help / start screen).
It is generated by `node scripts/build-example.mjs` from the images in `src/`.
Regenerate it whenever the project schema changes.

`dominus-dixit.mocquereau` é o projeto de exemplo embutido no Mocquereau.
É gerado por `node scripts/build-example.mjs` a partir das imagens em `src/`.
Gere-o de novo sempre que o schema do projeto mudar.

## Images / Imagens

Both images are crops (the line with the introit *Dominus dixit ad me*, Mass at cockcrow of
Christmas, with its neumes) taken through the IIIF image API of e-codices, downscaled to 2000 px wide.

| File | Manuscript | Page | Manifest | Page URL |
|------|-----------|------|----------|----------|
| `src/sg339.jpg` | St. Gallen, Stiftsbibliothek, Cod. Sang. 339 (Gradual, 10th c.) | p. 42 | https://www.e-codices.unifr.ch/metadata/iiif/csg-0339/manifest.json | https://www.e-codices.unifr.ch/en/csg/0339/42 |
| `src/e121.jpg` | Einsiedeln, Stiftsbibliothek, Codex 121(1151) (Graduale Einsiedeln, 10th c.) | p. 24 | https://www.e-codices.unifr.ch/metadata/iiif/sbe-0121/manifest.json | https://www.e-codices.unifr.ch/en/sbe/0121/24 |
